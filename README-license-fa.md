# راهنمای لایسنس

## روشن کردن لایسنس
تو `index.html`، اوایل بخش اسکریپت این خط رو پیدا کن:

    const LIC={required:false,server:''};

و `required` رو `true` کن:

    const LIC={required:true,server:''};

بعد از اون، اپ موقع اولین اجرا کد لایسنس میخواد. هر کد ۱۲ حرف و عدد داره (مثل `ABCD-EFGH-JKLM`).

## دو حالت
1. **بدون سرور** (`server:''`): فقط معتبر بودن کد چک میشه. شمارش ۵ بار استفاده انجام **نمیشه**، یعنی یه کد رو روی هر تعداد دستگاه میشه فعال کرد.
2. **با سرور** (پیشنهادی): شمارش ۵ دستگاه برای هر کد انجام میشه. برای این حالت باید Worker کلودفلر رو راه بندازی:
   1. تو cloudflare.com ثبت‌نام کن (رایگان).
   2. Workers & Pages ← Create ← Create Worker، و محتوای `worker.js` رو جایگزین کد پیش‌فرض کن، بعد Deploy.
   3. Storage & Databases ← KV ← Create، یه Namespace بساز.
   4. تو Worker: Settings ← Bindings ← Add ← KV namespace. اسم متغیر رو دقیقاً `LIC` بذار و Namespace رو انتخاب کن.
   5. آدرس Worker رو (مثلاً `https://xxx.workers.dev`) تو `index.html` بذار:
      `const LIC={required:true,server:'https://xxx.workers.dev'};`

## نکته‌ها
- هر دستگاه موقع فعال‌سازی یک بار از ۵ بار اون کد رو مصرف می‌کنه. فعال‌سازی دوباره‌ی همون دستگاه مصرف جدید حساب نمیشه، ولی پاک کردن اطلاعات مرورگر یا نصب مجدد یه دستگاه جدید حساب میشه.
- چون اپ تو مرورگر اجرا میشه، یه کاربر فنی میتونه چک سمت اپ رو دور بزنه. این لایسنس جلوی استفاده‌ی عادی و پخش کد رو میگیره، نه جلوی هکر.
- فایل `tokens.txt` رو جایی امن نگه دار و فقط به همراه ریپوی عمومی منتشرش نکن. توی `index.html` فقط هش کدها هست، نه خود کدها.
- ستون «تعداد استفاده» و «تحویل داده شده به» تو `tokens.csv` برای ثبت دستی خودته.
