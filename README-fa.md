# مدیریت مرغداری

## ۱) نسخه‌ی PWA (گیت‌هاب پیجز)
1. تو ریپوی `Chicken` فایل‌های `index.html`، `sw.js`، `manifest.json` و `.nojekyll` رو (بیرون از هر پوشه‌ای) آپلود کن.
2. Settings ← Pages ← Source: برنچ `main` و پوشه‌ی `/ (root)`.
3. آدرس: https://aasgharae.github.io/Chicken/
4. بعد از آپدیت فایل، یه بار صفحه رو رفرش کن (یا اپ رو کامل ببند و باز کن).

## ۲) ساخت APK و EXE (خودکار روی گیت‌هاب)
کل محتویات این پوشه (با پوشه‌های `native` و `.github`) باید تو ریپو باشه.
1. تو ریپو برو تب **Actions** ← **Build APK and EXE** ← **Run workflow**.
2. بعد از چند دقیقه، پایین صفحه‌ی اجرا (بخش Artifacts) دو فایل هست:
   - `android-apk` ← فایل `app-debug.apk` (روی گوشی نصب کن؛ اجازه‌ی نصب از منبع ناشناس لازمه)
   - `windows-exe` ← فایل `.exe` قابل حمل (بدون نیاز به نصب)
3. نسخه‌ی APK و EXE بعد از هر تغییر تو `index.html` دوباره با همین دکمه ساخته میشن.

## ذخیره‌ی خودکار تو پوشه
- ویندوز: `Documents\Poultry\poultry.sqlite`
- اندروید: `Documents/Poultry/poultry.sqlite` (اگه اندروید اجازه نده، پوشه‌ی داده‌ی خود برنامه)
- اگه برنامه رو دوباره نصب کنی و فایل تو اون پوشه باشه، اطلاعات خودکار برمی‌گرده.
